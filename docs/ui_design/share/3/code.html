分享图硬约束落地原则

1
长数字绝不从中间折断

如 142,895,400 Tokens 采用独立行单行容器，大数值与单位不拆行，保障可读性与专业感。

2
余额类拒绝伪造进度条

对于 DeepSeek / OpenAI 等纯余额或预充值卡片，以清晰大字展示余额与货币符号；如供应商本身无金额（如 GLM 免费卡），绝不臆造空金额。

3
花费附在对应指标内

如调用量或 Token 旁直接附折合花费（¥571.58），避免碎片化拆成无效孤立格子，信息紧凑聚焦。

4
不可篡改真实用量 vs 自由定制展示项

用户在右侧面板可隐藏任何敏感或冗余字段，但无法修改真实数值，保证凭证快照的客观真实性。
