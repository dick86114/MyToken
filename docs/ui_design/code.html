Questions & Answers

常见问题解答

有关架构安全、多 Key 机制与用量计算的真实解答。

help_outline

MyToken 是云服务还是本地应用？

MyToken 是一款 100% 纯本地运行的 macOS 原生菜单栏应用。它没有任何自有后端服务器、云端中转集群或统一用户账号系统。网络请求全部由您的 Mac 本机直接向供应商官方 API 发起。

help_outline

同一个供应商添加多个 Key 会合并计算额度吗？

绝不会。每个凭据拥有完全独立的配置卡片、独立查询任务与独立缓存沙盒。您可以在菜单栏或弹窗中分别查看工作号与个人号的额度，杜绝数据混淆。

help_outline

为什么 DeepSeek 等接口不显示百分比进度条？

因为 DeepSeek 采用按量计费的现金余额模型（无固定配额上限）。MyToken 遵循诚实透明的设计哲学，直接展示总余额、赠金与充值金明细，绝不通过捏造虚假的 100% 上限来绘制欺骗性进度条。

help_outline

Routin 签到与 Codex 检测会消耗我的额度吗？

完全不会。Routin 签到功能复用官方开放的抽奖端点，Codex 分组检测则通过极低载荷的元数据请求完成，不会产生实际的模型 Token 生成计费，请放心使用。

help_outline

卸载应用后会自动清除我的 API Key 吗？如何彻底清理？

macOS 将应用拖入废纸篓时默认保留沙盒偏好设置与 Keychain 项。如果您打算彻底注销，请在卸载前打开 MyToken 设置面板，点击底部的「重置并清除所有数据」，即可在秒级内完全抹除本地存储的全部凭据。
