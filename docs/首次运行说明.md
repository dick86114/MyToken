# MyRoutin 首次运行说明

## 安装

1. 打开 `MyRoutin.dmg`。
2. 将“MyRoutin”拖入“应用程序”文件夹。
3. 在“应用程序”中打开“MyRoutin”。

## 首次允许运行

MyRoutin 目前采用未签名方式交付。macOS 15 及更高版本对从网络下载的未签名应用会更严格，可能出现“无法打开”或应用没有任何界面。这通常是 Gatekeeper 拦截，不是应用运行时崩溃。遇到提示后：

1. 打开“系统设置 → 隐私与安全性”。
2. 在安全性区域找到 MyRoutin 的拦截提示，选择“仍要打开”。
3. 在随后出现的确认窗口中再次确认打开。

完成一次确认后，后续可正常从“应用程序”启动。

## 更新与发布

应用会在启动时检查 `dick86114/MyRoutin` 的最新 GitHub Release。发现新版本后，菜单栏弹窗和“设置 → 通知与系统 → 软件更新”会显示提示，可直接下载并安装；如果系统拒绝覆盖“应用程序”中的旧版本，请按提示手动打开 DMG 安装。

仓库的 CI 会在每次提交和 Pull Request 时运行测试并生成 DMG 构建产物。需要发布版本时，在 GitHub Actions 手动运行“发布版本”工作流，填写三段式版本号（例如 `1.2.0`），工作流会创建对应 Release 并上传 DMG。

## 问题反馈

如果遇到检查更新失败、下载失败或更新后未自动重启，可以在菜单栏图标上右键点击“提交问题”，或在“设置 → 通知与系统 → 软件更新”中点击“提交问题”。应用会打开预填充的 GitHub Issue 页面，并附带版本、系统信息和最近的脱敏诊断日志；最终提交前请自行确认 Issue 正文。

## 本地 Key 与卸载

你添加的 Key 会以本地明文形式保存在当前 macOS 用户的应用偏好设置中，不会随应用包分发。卸载 MyRoutin 不会自动删除这份本地数据；如需彻底移除，请先在应用内删除全部 Key，再卸载应用。
