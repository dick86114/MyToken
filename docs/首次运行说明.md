# Routin Usage 首次运行说明

## 安装

1. 打开 `Routin-Usage.dmg`。
2. 将“Routin Usage”拖入“应用程序”文件夹。
3. 在“应用程序”中打开“Routin Usage”。

## 首次允许运行

Routin Usage 目前采用未签名方式交付。macOS 的 Gatekeeper 首次可能会阻止应用运行。遇到提示后：

1. 打开“系统设置 → 隐私与安全性”。
2. 在安全性区域找到 Routin Usage 的拦截提示，选择“仍要打开”。
3. 在随后出现的确认窗口中再次确认打开。

完成一次确认后，后续可正常从“应用程序”启动。

## Keychain 与卸载

你添加的 Key 只保存在本机 Keychain，不会随应用包分发。卸载 Routin Usage 不会自动删除对应的 Keychain 项。如需彻底移除数据，请先在应用内删除 Key，再卸载应用。
