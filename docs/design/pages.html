01 · 凭证列表

它是“身份列表”，不是第二个首页

列表只回答：这是哪个凭证、是否启用、顺序是什么。用量留在首页，避免同一份数据在两处打架。

布局决策

  • 头部只留一个主操作：“添加”是蓝色 pill，导入收成 QR 图标；不再和帮助、导入、添加四个圆钮并列。
  • 每行：Logo → 名称 + 供应商/凭证类型 → 开关 → 更多。没有用量、没有状态色，只有“已停用”的中性小标签。
  • 排序：长按整行拖动，标题右侧只放一句“长按拖动排序”；拖动时卡片轻微抬起 + 触感反馈。
  • 隐私：列表底部一句“凭证只保存在本机”，比在设置里再解释一遍更靠近决策点。

关键交互

  • 点整行 = 编辑；开关 = 是否在首页显示；更多 = 编辑 / 删除。
  • 删除走确认弹窗，文案明确“只影响本机数据”。
状态覆盖：已停用（中性标签 + 开关关闭）、空列表（品牌标记 + “从 Mac 导入 / 手动添加”两个入口）、拖动中（轻微抬起 + 触感）。
02 · 新增凭证

先选供应商，再填最少字段

把 8 个供应商从一排会换行的 chip，收成“当前供应商一行 + 选择 sheet”。表单只显示这个供应商真正需要的字段。

布局决策

  • 供应商行：Logo + 名称 + 凭证类型 + “更换”；点开是 2 列供应商 sheet，选中项有 1px 强调描边和勾。
  • 表单分三段：基本信息 / 凭证 / 更多（可选）。每段一张卡，标签在输入框上方，不再用浮动 label。
  • 动作固定：底部“测试连接”次要 + “保存”主操作；测试结果在按钮上方以 6dp 圆点 + 一句话出现，不弹 toast。
  • 安全说明：“凭证加密保存在本机 Keystore”放在保存按钮之前，给用户一个明确的决定依据。

字段随供应商变化

03 · 设置

按“我会改什么”分组，而不是按代码模块

五组：外观、刷新、通知、数据、关于。开关类设置留在行内，跳转型设置用图标 + 值 + 箭头，信息密度一目了然。

布局决策

  • 顶部只保留品牌与版本：不再有独立的“隐私与刷新”帮助卡，隐私信息合并到“凭证只在本机”一行。
  • 外观用分段控件：跟随系统 / 浅色 / 深色，当前项直接可见，不用点开再选。
  • 设置卡内不再画分割线：用 12dp 行距和左右对齐分组；开关和跳转型行只在尾部控件上区分。
  • 关于合并：版本、检查更新、更新日志、更新源与令牌放在同一组；权限与更新状态只用一个中性或警告色点。

关键交互

  • 主题切换即时生效，并同步到首页与小组件。
  • 通知权限未授予时，该行出现琥珀色“未授予”和“去授权”文字按钮；已授予时只显示中性“已允许”。
  • 发现新版本时，“检查更新”显示“可更新至 6.0.3”，首页的更新提示条同步出现。
状态覆盖：通知权限未授予、发现更新 / 已是最新、日志导出中、更新源 CDN / GitHub。
04 · 卡片详情

一张卡展开成一页，而不是把卡片再抄一遍

首页的弧线、状态、重置时间在这里放大；其余信息按“用量 → 订阅 → 账户 → 配置”推进，最后才是操作。

布局决策

  • Hero 只有一件事：88dp 弧线 + 剩余比例 + 重置时间 + 重置卡入口；状态只出现一次（接近上限）。
  • 全部窗口：5 小时与周各一行，百分比 + 细条 + 剩余 + 重置；重置卡的完整到期日期直接展开，不再藏在弹层里。
  • 订阅与账户：六项事实用 2 列网格，取消“套餐状态 / 订阅与周期”两张重复卡；模型以 chip 呈现，点击复制。
  • 数据时间：合并到 Hero 页脚，删除详情页里“最近更新 / 数据时间”这类重复行。

关键交互

  • 底部“编辑 / 立即刷新”固定；刷新时 Hero 数值 500ms 过渡，不整页闪。
  • 分享在导航栏，删除收进“更多”，删除前确认。
  • 失败时 Hero 页脚变成红色“更新失败 · 上次成功 19:40”，并出现重试文字；数据保留。
状态覆盖：接近上限 / 已超限 / 待刷新 / 更新失败 / 余额型（金额 + 余额构成替代弧线）/ 多币种（下方分组）。
