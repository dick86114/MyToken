# MyToken Android 设计稿

## 最新首页设计（2026-11-22）

**首页最新版本：[home-latest.html](home-latest.html)。** 用户已选定 01「琥珀警示票」作为报告样式；此稿替代旧首页稿中的顶部布局与切换交互。用量卡片继续复用 `home-hifi.html` 的结构与排版。

- 左侧 Logo / 名字，右侧设置；报告内显示数量、仪表盘、可定位条目、同步时间与刷新。
- 供应商选择从底部弹出；简洁 / 完整改为黑白图文滑块。
- 左右拖动仅移动用量卡片，两页连续跟手，松手按距离 / 速度停靠；纵横方向互不串页。
  纵向上滑时报告随卡片收起，固定导航过渡为黄色并显示摘要；供应商工具条不固顶。
- 所有卡片之后紧接「新增凭证 / 管理已有凭证」，底部留白 12dp；新增直接进入新增页（供应商板块对齐 Debug 的 64dp 行），管理从底部打开现有凭证列表。
- 简洁 / 完整切换只保留双列与单列图标，不再显示文案；悬停提示与无障碍名称仍为「简洁 / 完整」。
- 设置保留当前 Debug 内容与从右向左的抽屉方向；外观改为「跟随系统 / 浅色 / 深色」三张主题预览卡，用墨色描边表示选中。
- 凭证列表内容保留启停、更多操作、排序与添加入口。
- 报告定位后做三次递减跳动；减少动态时使用静态描边。

`home-report-refinement.html` 与 `home-directions-v2.html` 保留为历史探索。最新稿为独立 HTML，无需构建；原型交互不写入真实数据。生成来源为 `build-home-latest.py`、`home-latest-interactions.css/js` 及前一轮报告模板。

## 与实现同步（2026-11-21）

三份 HTML 已按 Android 落地结果回写，后续改动以这里和实现规格为准：

- 简洁卡高度随内容自适应，首页简洁网格用瀑布流（`LazyVerticalStaggeredGrid`，HTML 用 CSS columns 模拟）。
- 重置卡 chip：简洁 17px 仅数字，完整 19px「重置卡 N」；主指标 chip 换行到标签下方，窗口 chip 紧跟窗口标签。
- 供应商 logo 保持 24px（简洁）/ 28px（完整），不再放大。
- CommandCode 简洁卡只保留窗口细条，不再重复余额行。
- 余额构成图例在简洁卡纵向排列（行距 8px）；完整卡图例与 facts 间距同步加大。
- 凭证列表入口图标为「两长一短」三横线；健康标尺到卡片区间距 14px。
- 设置页分组间距 18px、资料卡距页头 6px；刷新/通知行补齐设计稿的说明文案。
- 设置页品牌位使用产品 logo（`mytoken_brand_logo`），不再是「M」占位。
- 「关于」为常显卡片：版本 / 检查更新 / 更新日志 / 更新源与令牌四行。
- 抽屉拖动竖条在面板边框与 16px 页边距之间居中（距边框 8px）。
- 详情页 Hero 默认取周期最短的额度；「全部窗口」按 5 小时 → 周 → 月排序，月固定在最后。
- 详情页重置卡按到期日拆成日期 chip（叠卡图标 + `MM-dd HH:mm`），不再拼成一行。
- 「账户与模型」不再展示分组倍率；允许模型默认折叠为堆叠卡（首个模型 + 总数），点击展开为两列紧凑模型行，行内点击复制，底部「收起」。
- 「配置」官网地址完整展示并允许换行，超长 URL 不截断。
- 详情页右上角菜单继续使用 `core-ui` 的 `MyTokenDropdownMenu`；首页「全部供应商」改为设计稿的底部选择面板。
- 设置页保留资料卡与分组卡；外观改为三张 54dp 主题预览卡（系统左右分色、选中 2dp 墨色描边），分节标题 11.5sp 且中文不加字距，数据行图标使用 28dp 底板。
- 首页左右滑动只切换用量卡片（左滑完整、右滑简洁），卡片连续跟手、松手停靠，图标滑块随分页进度移动；凭证列表与设置只通过左上/右上按钮弹出，内容区滑动不再打开抽屉。

## 与实现同步（2026-11-22）

- 首页头部按 `home-latest.html` 落地：品牌标使用用户提供的两张原始 PNG（浅色黑标 / 深色白标，带原生投影）+ 设置入口、琥珀报告、供应商工具条与 104×42dp 纯图标密度滑块；发现新版本时报告上方显示黄色更新提示条，设置入口同时保留黄色提示点。
- 报告在任何健康状态下都保持琥珀票面，不随全部正常退回灰色；正常时只省略风险条目，保留数量、仪表盘和同步行。
- 简洁 / 完整两页会预组合并保留滚动状态，滑动切换时控件不会重新加载或闪动；非当前页不参与无障碍语义。
- 报告口径始终是全部启用凭证，不受供应商筛选影响；点击风险项定位卡片，若被筛选隐藏则先清除筛选。报告底部提供同步时间与刷新全部；全部正常时不再显示两行说明，只保留同步行。
- 报告按设计稿切角：左上/右下 20dp 圆角，右上/左下 20dp 切角；使用背景 Shape 而非 `Modifier.clip`，确保风险项和刷新按钮可点击。
- 上滑时报告和供应商工具条一起完全收起；头部与分页内容共用同一份绘制位移，分页区高度不变，快速 fling 不重排。固定导航保留 logo 并渐变为报告黄，品牌字标上移淡出，报告摘要（如「7个凭证 用量正常」）横向淡入到 logo 右侧，报警凭证的供应商 logo 继续向右排列。下拉到列表顶部后继续下拉可重新展开报告。
- 下拉刷新只从报告上方的页面顶部触发：指示器是透明双箭头图标，出现在报告上方并把内容整体下推，不铺整行或圆形底色；只有手势开始时列表已在顶部才生效，从列表下方一路滑到顶部不会触发刷新。报告内刷新按钮同样只保留透明图标。
- 供应商筛选已改为底部选择面板：两列供应商 tile + 全宽全部供应商 tile，显示数量与选中勾。
- 卡片末尾只保留居中的「管理凭证」文字胶囊；凭证列表页右上角「添加」改为黄色。管理面板从底部滑出并复用凭证列表，不再叠加状态栏内边距，顶部留白与新增面板一致。
- 所有开关统一使用报告票面黄轨道 + 深色滑块；简洁 / 完整切换只做绘制阶段位移，图标颜色不做加载动画，点击或左右滑动时不再整块闪动。
- 所有蓝色交互强调统一改为报告票面黄，包括新增凭证页文字/按钮/边框、主页更新点、设置页文字/图标/按钮。
- 设置页按设计稿同步：关闭 X 在右；资料卡使用产品 logo（浅色黑标 / 深色白标）；主题为三张预览卡；数据行图标带 28dp 底板；已授权通知使用中性对勾。
