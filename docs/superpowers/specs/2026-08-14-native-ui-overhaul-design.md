# MyRoutin 原生界面重构设计

## 目标

将 MyRoutin 从以文字堆叠为主的菜单栏工具，重构为更易扫描、符合 macOS 原生习惯的用量管理界面。保留现有 Key、用量刷新、签到、更新、分组检测与持久化行为，不修改任何业务数据模型或接口。

## 设计方向

- 目标用户：需要高频查看多个 Routin plan Key 用量的个人用户。
- 视觉语言：原生 macOS 工具界面，石墨色系统材质、清晰层级、克制留白。
- 设计参数：变化度 4，动效 2，信息密度 6。
- 品牌色：继续使用应用当前强调色；绿色、橙色、红色仅表达用量风险。
- 适配：优先支持 macOS 14 及以上，跟随系统深浅外观与辅助功能设置。

## 当前问题

1. 设置窗口的顶部标签占据较多空间，但“显示与刷新”“通知与系统”内容较少，页面视觉失衡。
2. Key 列表把套餐、时间、分组、模型等全部平铺为小字，账户之间难以快速比较。
3. 设置页的 `ProgressView` 在实际深色界面中不稳定地显示系统蓝色，无法可靠传达用量风险。
4. 菜单栏弹窗、设置、引导和 Key 编辑的标题、按钮、数据块没有形成一致的信息优先级。

## 信息架构

### 设置窗口

- 改为 `NavigationSplitView`：侧栏入口为“账户”“显示与刷新”“通知与系统”。
- 默认窗口尺寸提升至适合账户概览的桌面宽度，保留最小尺寸和用户调整尺寸持久化。
- 侧栏只承担导航，详情区域展示对应页面，不改变任何设置项语义或位置归属。

### 账户概览

- 每个 Key 以一条可扫描的账户行呈现：选中状态、别名、掩码 Key、编辑与删除操作在顶部。
- 周期套餐显示“5 小时”和“周”两个并列用量块；资源包显示一个 Token 用量块。
- 用量块展示标题、百分比、细进度条、已用/剩余和重置时间。
- 套餐、订阅起止时间、分组倍率、关联账号、允许模型移入“详情”展开区，默认不干扰比较。

### 菜单栏弹窗

- 保留弹窗宽度、左右键交互和所有状态入口。
- 统一使用新的细进度条与风险色，增强当前 Key 的选中状态。
- 版本与低频信息弱化，刷新、签到、设置、退出保持可发现的原生图标操作与辅助功能标签。

### 引导与编辑

- 首次引导展示 Routin 品牌图而不是通用图标，文案和主操作聚焦“添加第一个 Key”。
- Key 编辑沿用系统 Form，收紧间距和按钮层级，错误与成功状态保留现有行为。

## 共享组件

- 新增 `UsageMetricPresentation`：统一计算合法百分比、风险颜色和进度条长度。
- 新增 `UsageMetricProgressBar`：使用自绘细胶囊条替代不稳定的系统 `ProgressView` 染色，浅色和深色界面都保持颜色语义。

## 交互与兼容

- 账户排序、选择当前 Key、编辑、删除、签到、更新、分组检测均保持原有入口与行为。
- 所有图标按钮提供 `.help` 与辅助功能标签。
- 空状态、加载状态、错误状态继续显示现有业务文案。
- 不新增网络请求、权限、第三方依赖或持久化字段。

## 验收

1. 设置窗口显示原生侧栏，三组设置完整可用。
2. 周期套餐在账户概览中同时展示两条可对比的图形化用量，资源包展示 Token 用量。
3. 小于 50%、50% 至 79%、80% 及以上的进度色分别为绿、橙、红。
4. 菜单栏弹窗与设置页使用同一进度条组件。
5. 现有单元测试、构建与工作区差异检查通过；实际启动后检查设置页三个入口。
