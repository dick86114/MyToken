# 菜单栏显示样式设计

## 目标

为 MyRoutin 增加可持久化的菜单栏显示样式。用户可在“显示与刷新”设置页选择：

- 仅百分比（默认，保持现有行为）
- 别名 + 竖形进度条
- 别名 + 百分比

所有样式均对应当前选中的 Key，并继续受“5 小时 / 周”周期维度控制。

## 交互与视觉规则

### 别名 + 竖形进度条

- 显示截断后的 Key 别名，后接一个宽约 7pt、高 18pt 的竖形胶囊柱。
- 胶囊柱底部向上填充，填充比例为当前所选维度的已用百分比，限制在 0% 至 100%。
- 用量低于 80% 为绿色，80% 至 94% 为黄色，95% 及以上为红色，与总览中的用量风险颜色一致。
- 没有有效百分比时不显示不确定的胶囊柱，继续显示现有状态文本：未配置为 `--`，首次加载为 `…`，错误为 `!`。

### 别名显示

- 别名最多显示 6 个字符；超出时保留前 5 个字符并以省略号结尾。
- 菜单栏悬停提示始终保留完整别名、刷新时间和缓存状态。

### 别名 + 百分比

- 显示截断后的别名、一个空格和当前整数百分比，例如“主账号 72%”。
- 没有有效百分比时使用现有状态文本，不额外追加别名。

## 架构

- 在 `AppSettings` 增加 `menuBarStyle` 属性和 UserDefaults 键，使用 `MenuBarStyle` 枚举表达三种样式。
- 在 `MenuBarLabelView` 根据样式组合文字或绘制竖形胶囊柱。
- 将别名截断和菜单栏文本组合提取到可测试的格式化接口，避免视图内包含业务判断。
- 在 `SettingsView` 的“菜单栏显示”区域添加样式 Picker。

## 错误处理与兼容性

- 读取到未知或损坏的样式持久化值时回退为“仅百分比”。
- 既有用户没有样式设置时保持“仅百分比”，不改变原有菜单栏宽度与展示内容。
- 周期订阅按当前 5 小时或周维度取数；Token 资源包继续忽略周期维度，显示 Token 总用量。

## 测试

- `AppSettingsTests`：默认值、合法样式的持久化与未知值回退。
- `UsageFormatterTests`：别名截断、三种样式的有效百分比及加载/错误回退文本。
- `ProjectBootstrapTests`：设置页包含样式选择器，菜单栏视图使用自绘竖形胶囊柱。
- 运行完整 `xcodebuild test` 和 DMG 构建验证。

## 本轮追加需求

### 设置窗口尺寸

- 设置窗口允许用户拖动窗口边角调整宽高，不设置固定最大尺寸。
- 持久化窗口宽度和高度；设置窗口再次打开时恢复上一次尺寸。
- 继续保留安全的最小宽度和最小高度，避免列表和表单不可用。

### Key 本地存储与查看

- 不再请求或使用系统钥匙串。
- plan Key 直接保存在 App 本地偏好设置中，接受本地明文存储风险。
- Key 管理列表默认继续显示掩码。
- 每个 Key 增加眼睛图标：点击后临时显示完整 Key，再次点击隐藏。
- 显示状态只保存在当前设置窗口内，关闭设置窗口后自动隐藏，不持久化查看状态。
- 删除和更新 Key 时同步更新本地 Key 存储。

### 弹窗信息调整

- 弹窗不再显示允许模型清单；设置页的 Key 详情仍可保留该信息。
- 5 小时剩余时长使用接口的 `dayWindowEndAt` 减去当前时间计算，格式为 `3h45m`。
- 周剩余时长使用 `weekWindowEndAt` 减去当前时间计算，格式为 `4d3h45m`。
- 倒计时以接口解析出的绝对时间和当前绝对时间计算，避免时区转换造成偏差；展示时使用用户当前时区。
- 窗口已结束时显示“已结束”，缺少时间字段时显示“—”。
- 分组倍率使用 `groupNames` 与 `groupMultipliers` 的对应索引，显示为 `Codex ×1、Codex Pro ×2`；数组长度不一致时只显示可配对的项目。
- 订阅开始时间映射接口字段 `startAt`，结束时间映射 `endAt`。

### 兼容与测试补充

- 本地 Key 存储替换现有 Keychain 依赖后，网络请求、缓存和通知逻辑的公开接口保持不变。
- 新增测试覆盖本地 Key 的新增、读取、更新、删除和眼睛图标临时显示状态。
- 新增窗口宽高持久化、倒计时的时区/已结束/缺失字段、分组倍率配对测试。
- 更新弹窗测试，确认允许模型不再渲染，并确认显示两个倒计时和分组倍率。
